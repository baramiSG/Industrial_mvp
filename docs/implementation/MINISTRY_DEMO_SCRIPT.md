# Ministry Demonstration Script

## 1. Opening — 45 seconds

> “This is not another list of opportunity scores. The system resolves what the product is, tests what Saudi plants can already do, and recommends the smallest action that changes the outcome. It can also tell us when to spend nothing.”

Point to the evidence-mode toggle and frozen snapshot date.

## 2. Steel public case — 3 minutes

Open HS 721049 in **Public Evidence**.

Show:

1. imports and quantity trend;
2. R2 quantity-led expansion;
3. R3 concentration;
4. domestic galvanising capability;
5. D\* withheld because capacity and customer qualification are unresolved;
6. public decision `INVESTIGATE`;
7. exact missing facts.

Say:

> “The public data is already valuable because it blocks the lazy conclusion that high imports mean a new factory. Saudi capability exists, so brownfield must be tested first.”

## 3. Switch on Ministry simulation — 3 minutes

Switch to **Ministry Simulation**.

Pause on the dual states:

```text
REAL: INVESTIGATE → SIMULATED: ADVANCE
```

Show:

- synthetic disclosure;
- effective qualified capacity 57.509 kt;
- target-specification gap 46.491 kt;
- incremental-upgrade capability band;
- unsupported NPV −SAR 18m and IRR 9.5%;
- S\* SAR 18m;
- incremental national value SAR 198m;
- capacity ratio below 1.25;
- conditions and kill conditions in the dossier.

Say:

> “This is exactly what your line-level records unlock. We do not just become ‘more accurate.’ We move from a named evidence request to a defensible route, minimum intervention and protected decision.”

## 4. Polypropylene case — 2 minutes

Open HS 390210.

Show:

- exports above 50× imports;
- R2 does not fire;
- generic support is rejected;
- simulation confirms qualified supply above demand.

Say:

> “More data does not automatically create a project. Here it confirms that the correct intervention is zero. The engine protects the Ministry from paying for redundant capacity.”

## 5. Close — 45 seconds

Open the Decision Dossier.

> “The output is not software theatre. It is a reproducible decision record: evidence, route, economics, conditions, kill condition and the next fact that matters. We can begin with public data, then connect and clean the Ministry’s data in the same structure to make many more cases decisive.”

## 6. Expected questions

### Is the synthetic data pretending to be Ministry data?

No. It is Class D, visibly labeled, isolated and technically incapable of changing the real decision.

### Why not rank all 1,300 products immediately?

The system can screen the universe, but final routes require product/specification resolution. A single ordinal list hides false positives and route differences.

### Does this replace technical experts?

No. It concentrates experts at genuine hard gates and authorization points instead of asking them to perform repetitive data assembly.

### What data should the Ministry provide first?

The engine’s data-unlock queue identifies the minimum route-changing fields: line production/capacity, invoice specification, customer qualification, flow decomposition and economics.
